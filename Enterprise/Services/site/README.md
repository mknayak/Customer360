# Site Service

Owns physical and digital sites plus customer visits in the service-owned
SQLite database at `data/site.sqlite3`.

## API

- `POST /api/sites`
- `GET /api/sites`
- `GET /api/sites/{site_id}`
- `PUT /api/sites/{site_id}`
- `DELETE /api/sites/{site_id}`
- `POST /api/visits`
- `GET /api/visits`
- `GET /api/visits/{visit_id}`
