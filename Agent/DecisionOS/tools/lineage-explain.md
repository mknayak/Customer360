# lineage.explain

## Purpose

Explain where a metric or evidence item came from and how it was transformed.

## Required inputs

```text
claim_ids
metric_ids
source_scope
user_context
```

## Output

Return definition, source systems, tables or documents, transformations, filters, query references, data owner, freshness, quality checks, and known limitations.

The tool must not expose restricted source details to unauthorized users.
