# Customer360 Domain Registry

## Agents

- `customer-intelligence`
- `product-intelligence`
- `promotion-intelligence`
- `digital-intelligence`
- `voice-of-customer`
- `finance-intelligence`

The `executive-orchestrator`, `evidence-validator`, and `memory-steward` remain core-level roles with Customer360 capabilities registered into them.

## Domain capabilities

```text
customer360.crm
customer360.product
customer360.shopping
customer360.site
customer360.feedback
customer360.marketing
customer360.simulation
customer360.analytics
customer360.knowledge-graph
customer360.rag
```

## Initial metrics

```text
customer360.revenue
customer360.conversion
customer360.cart-abandonment
customer360.retention
customer360.customer-frequency
customer360.promotion-roi
customer360.gross-margin
customer360.product-performance
```

Each metric must be implemented through the semantic-layer contract before an agent can use it in a decision brief.
